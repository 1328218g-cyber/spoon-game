쿠키는 어떻게 얻나요?
PC에서 get_session_cookies.js를 한 번 실행해 스푼 로그인을 완료하면 session_cookies.json 파일이 생성돼요. 그 파일 내용을 통째로 복사해서 위 칸에 붙여넣고 업로드하면, 이후로는 서버가 PC 없이 알아서 로그인 상태를 유지합니다. 세션이 만료되면 이 과정을 한 번 더 반복하면 돼요.

실시간 채팅
⏱ 효과음 재입장 쿨다운(환영 메시지 음원 전용)

같은 유저가 짧은 시간 안에 여러 번 입장해도 효과음이 반복 재생되지 않도록 제한합니다.
※ 환영 메시지 음원에만 적용됩니다. (채팅 멘트는 그대로 출력)
※ 0초로 설정하면 비활성화 (입장할 때마다 매번 재생)

메시지 설정항상 켜짐

※ 지금은 입장·좋아요·퇴장·반복문구 탭이 실제로 채팅에 전송돼요. 선물 탭은 화면만 먼저 만들어둔 상태예요.

💰 펀딩 관리

펀딩을 생성하고 관리합니다. 채팅창에서 설정한 명령어로 [명령어] [번호] [숫자]로 적립합니다.

출력 옵션:
⚙️ 펀딩 명령어 및 문구 커스텀
변수: {month}
변수: {index}, {title}, {current}, {goal}, {percent}, {dday}
📋 명령어 안내

· !펀딩 → 진행중인 펀딩 목록 출력
· !펀딩 2 200 → 2번 펀딩에 200 적립 (DJ 전용)
· !펀딩 2 -50 → 2번 펀딩에서 50 차감 (DJ 전용)

📝 새 펀딩 추가
⌨️ 단축키 명령어

단축 명령어를 등록하면 채팅창에서 등록한 단어로 빠른 메시지를 출력할 수 있습니다.

새 단축키 명령어
{nickname} {tag} {count} {host_nickname} {host_tag} {rank}

{nickname}/{tag}: 명령어를 친 시청자 정보 · {count}: 이 명령어 사용 횟수
{host_nickname}/{host_tag}/{rank} 등 랭킹 변수는 아직 준비 중이라 빈 값으로 출력돼요.

🙋 지정 인사 설정

특정 고유닉(Tag)을 가진 유저가 입장할 때 출력될 전용 메시지를 설정합니다. 등록해두면 일반 입장 메시지 대신 이 인사말이 나가요.

🚩 단비 깃발

깃발 목표를 만들고, 자동 적립 또는 수동 적립을 설정하며, !깃발 명령어나 주기 출력으로 상태를 보여줄 수 있습니다.

사용 예시

· !깃발 → 등록된 전체 깃발 상태 출력
· !깃발 1 → 1번 깃발만 출력
· !깃발 1 50 → 1번 깃발에 50 적립 (DJ 전용)
· 자동 적립 선택 시 스푼을 받으면 선물 수량만큼 자동 누적됩니다.

변수: {실드}

🔑 실드 조절 권한 관리 (DJ 전용 설정)
※ 여기에 등록된 고유닉 사용자만 실드 적립/차감이 가능합니다. (DJ는 기본 포함)
🛡️ 실드 명령어 안내

· !실드 : 현재 남은 실드 개수를 출력합니다.
· !실드 +5 : 실드를 5개 추가합니다. (DJ/지정 권한자 전용)
· !실드 -3 : 실드를 3개 차감합니다. (DJ/지정 권한자 전용)

🎵 신청곡 관리

시청자들이 !신청곡 [가수] [제목]으로 신청한 목록을 관리합니다.

⚙️ 신청곡 명령어 및 문구 커스텀
변수: {artist}, {title}, {count}
변수: {index}, {artist}, {title}

✏️ 채팅 글자 제한 분할 설정

스푼라디오 채팅창 글자 제한으로 목록이 잘릴 때, 자동으로 여러 메시지로 나눠서 전송합니다.

📋 신청곡 명령어 안내

· !신청곡 : 대기 중인 목록을 출력합니다.
· !신청곡 [가수] [곡이름] : 곡을 신청합니다.
· !제거 [번호] : 특정 곡을 제거합니다. (DJ 전용)
· 리셋 : 목록을 초기화합니다. (DJ 전용)
· !마감 / !접수 : 신청곡 접수 상태를 변경합니다. (DJ 전용)
· !현재곡 : 현재 재생 중인(1번) 곡을 채팅으로 알립니다.

🎡 룰렛 시스템 설정

최대 10개의 룰렛을 관리합니다. 지정한 스푼만큼 선물을 받거나, 지정한 스티커를 선물 받으면 조건에 따라 즉시 자동으로 룰렛이 돌아가요. !룰렛N [수량]으로 룰렛권을 사용해 수동으로 돌릴 수도 있어요 (룰렛권은 "룰렛 기록"에서 직접 지급).

🎉 결과 문구 커스텀
변수: {룰렛명}, {닉네임}
변수: {닉네임}, {번호}, {룰렛명}, {요청}, {보유}

기준 스푼(X)만큼 선물이 들어오면 설정한 지급 방식대로 룰렛이 실행돼요.

지정한 스티커를 연속(콤보)으로 선물한 개수만큼 그대로 룰렛이 실행돼요.

스푼 공식 스티커 목록에서 골라도 되고, 이름을 직접 입력해도 돼요.
