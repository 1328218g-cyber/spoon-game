세션 상태확인 중...

봇이 방송에 들어가서 채팅을 보내려면 스푼 로그인 세션이 필요해요. 아래 프로그램을 설치해서 딱 한 번만 로그인해두면, 그 뒤로는 완전히 자동으로 계속 연결이 유지돼요.

별도로 연결하지 않으면 지금처럼 관리자 공용 계정으로 계속 동작하니, 굳이 본인 계정을 쓰고 싶은 경우가 아니라면 이 화면에서 따로 할 일은 없어요.

🖥️ 에디봇 자동로그인 (윈도우 프로그램)

설치하고 딱 한 번만 로그인하면, 그 뒤로는 트레이(작업표시줄 오른쪽 아래 숨겨진 아이콘)에 조용히 상주하면서 알아서 로그인 상태를 계속 유지해줘요. Node.js 설치, 크롬 확장프로그램, 터미널 명령어 전부 필요 없어요.

설치 방법 (총 1분)

1. 다운로드한 에디봇_자동로그인_Setup.exe 실행 → 설치 (윈도우가 "알 수 없는 게시자" 경고를 띄우면 "추가 정보" → "실행" 클릭)

2. 설치되면 자동으로 작은 창이 떠요 → 이 웹 대시보드에 로그인할 때 쓰는 본인 아이디/비밀번호 입력 (스푼 계정 아니에요!)

3. "스푼 로그인 창 열기" 버튼 클릭 → 평소처럼 스푼에 로그인 (카카오/구글 등 편하신 방법으로)

4. 로그인만 완료하면 자동으로 감지돼서 창이 알아서 닫혀요. 이제 끝!

✅ 이후로는 방송 켤 때 이 프로그램만 켜져있으면(트레이 아이콘 확인) 완전히 자동으로 계속 유지돼요. 세션이 만료되면 알림이 뜨는데, 그때 트레이 아이콘 우클릭 → "스푼 재로그인"만 눌러주시면 돼요.
※ 컴퓨터 켤 때 자동으로 같이 켜지게 하고 싶으면, 트레이 아이콘 우클릭 → "컴퓨터 켤 때 자동 시작" 체크해두세요.
